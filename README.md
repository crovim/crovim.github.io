# Clovis Junior · Data Portfolio

Site estático: `index.html` + os dois PDFs (currículo e cover letter), que os botões de download da página usam. Os três arquivos precisam ficar na mesma pasta do repositório.

## Atualizar o site no GitHub Pages (crovim.github.io)

1. Abra o repositório `crovim.github.io` no GitHub.
2. **Add file → Upload files** → arraste `index.html`, `Clovis_Junior_CV.pdf` e `Clovis_Junior_Cover_Letter.pdf` → **Commit changes** (substitui o `index.html` antigo).
3. Acompanhe em **Actions** o workflow "pages build and deployment" (1–2 min).
4. Abra o site com **Ctrl + Shift + R** (ou numa aba anônima) para não ver a versão em cache.

Links diretos para cases funcionam, por exemplo:
`https://crovim.github.io/#case-pix-fraud`
